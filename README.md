# こもれび — Virtual Cat Café

6匹の猫が気ままに暮らす、ブラウザの中の3D猫カフェ。Vite / JavaScript / Three.js。

公開サイト: https://zaaaato.github.io/catcafe/

## 起動とビルド

Node.js 22.12 以降を使用してください。

```sh
npm install
npm run dev         # http://localhost:5173
npm run check       # 自動テスト + 本番ビルド
npm run preview     # http://localhost:4173
```

`dist/` を静的Webホスティングへ配置できます。バックエンド・APIキー・登録は不要です。WebGL 2 対応ブラウザとハードウェアアクセラレーションが必要です。

## 猫たちとの過ごし方

- **見回す**：ドラッグ / 1本指スワイプ。ホイール / ピンチ / ＋−でズーム。
- **猫のそばへ**：一覧から選択。滑らかに近づいて猫を追いかけます。
- **ふれあい**：「そばで、ふれあう」から、頭や背中をなでる・ブラシ・おやつ。ふれあい中はドラッグで視点が回らないよう固定します。
- **おもちゃ**：低く構える → お尻を振る → 飛びつく → 見失って探す。
- **おやつ**：高い場所の猫も降りて、皿へ集まります。
- **のんびり**：歩く、座る、前足を舐めて顔を洗う、ふみふみ、伸び、眠る。ソファやタワーにも飛び乗ります。
- **写真**：カメラボタンで撮影し、プレビューからPNGをダウンロード。
- **設定**：カフェ・雨・庭の3環境音、音量、描画品質3段階、控えめな動き。昼と夕暮れも切り替えられます。
- **プロフィール**：6匹の性格・好きなもの・親密度。
- **観察ノート**：この訪問で実際に見つけた7種類のしぐさを記録。まだ見ていない動きにはヒントも。

キーボードの基本操作：`1`〜`6` 猫を選択、`P` なでる、`R` 視点を戻す、`C` 撮影、`+` / `-` ズーム、`Esc` ダイアログやふれあいを終了。画面のボタンからも操作できます。

## 隠しバトル

左上の猫アイコンを約4秒見つめる（ホバーする）と、震え始めて秘密の魔法アリーナが開きます。スマートフォンでは長押し、キーボードではアイコンにフォーカスしてEnterまたはSpaceを長押し。途中で離すとキャンセルします。URLは変わりません。再読み込みで通常のカフェへ戻ります。

きなこ＝炎、もち＝氷、くろ＝闇、みけ＝風、ごま＝雷、ちゃい＝大地。それぞれ通常技3つと究極技1つを持ち、6匹全員が自分で移動・相手選び・技選びを行うバトルロワイヤルです。切り替わるとカウントダウンなしで始まります。通常カフェの操作要素は表示したままdisabledになり、ユーザーは観戦だけになります。

HPが0になると横向きに倒れ込み、そのラウンド中は復帰しません。最後の1匹が勝者になり、結果を眺めたあと自動的に次のラウンドが始まります。燃焼・凍結・しびれ・減速・吹き飛ばしが行動に影響します。バトルの状態はカフェの親密度に影響しません。

## 猫同士のふれあい

「のんびり」で見守っていると、起きている猫同士が鼻先で挨拶し、前足を交互に出して遊び、短い追いかけっこをします。一度に遊ぶのは1組。お昼寝中・高所への移動中・人とのふれあい中の猫は誘わず、おもちゃやおやつに切り替えるとそちらを優先します。新しい3つのしぐさは観察ノートにも記録されます。

## 猫モデル

猫、家具、毛柄、音はこのプロジェクトで独自に生成しています。猫は写実的なスキャンではなく、柔らかな立体感を持つスタイライズモデルです。

部位別の毛柄、光を映す瞳、耳の内側、立体的な口元、ひげ、肉球、先細りのしっぽを持ち、関節に合わせて前足・後足・頭・耳・しっぽを動かします。しっぽは根元から先へしなりが伝わり、歩行・甘え・狩り・座り・睡眠で振幅と先端の動きが変わります。歩行は移動距離と足運びを連動。高所は予約制で重なりを防ぎ、ジャンプ中にモードが変わっても着地してから降ります。

## 保存と外部通信

設定・親密度・案内を閉じた状態は、この端末の同じブラウザの `localStorage` にのみ保存します。保存できない環境でもメモリ内で動作し、破損データは安全な初期値に戻します。ブラウザデータの削除で記録も消えます。音は毎回オフから始まります。

アカウント、広告、アクセス解析、写真のアップロードはありません。フォントのためGoogle Fontsへ接続します。利用できない場合はシステムフォントへ切り替わります。モデル・音声アセットの外部ダウンロードはありません。

## 検証

```sh
npm test                     # 永続状態・音声ライフサイクルの回帰テスト
npm run test:scene:prepare    # 最新シーンをテスト用に固定
npm run dev
```

実ブラウザで `http://localhost:5173/tests/scene-harness.html` を開き、開発者コンソールで `await cafeHarness.runSmoke()` を実行できます。実WebGLと仮想時計で、しぐさ・高所・おやつ・ふれあい・写真・破棄/再生成を確認します。ハーネスは本番ビルドに含まれません。

`tests/state.test.js` は壊れた保存値、保存拒否、連打、別タブ同期を検証。`tests/audio.test.js` は再生拒否、ON/OFF競合、非表示からの復帰、破棄中の非同期処理を検証します。

検証範囲と再現方法の詳細は [QA.md](QA.md) を参照してください。

## GitHub Pages

個人リポジトリ `zaaaato/catcafe` の `main` へのpushで、GitHub Actionsがテスト・ビルド・公開を行います。公開用のURLパスはPagesの設定から取得し、Viteのbaseへ渡します。独自ドメインへ変更した場合も、Pages設定に合わせてビルドされます。

GitHubリポジトリの Settings → Pages → Source は **GitHub Actions** を選択してください。公開対象は `dist/` のみで、テスト用ハーネスやローカル検証画像は含まれません。
